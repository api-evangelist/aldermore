# Aldermore Bank

> Aldermore Bank plc is a UK specialist bank (founded 2009, Reading) offering savings and specialist lending (residential and buy-to-let mortgages, commercial and property finance, asset, invoice and motor finance). It is a branchless specialist lender, NOT a CMA9 current-account bank, so its UK Open Banking (OBIE/PSD2) footprint is minimal. No Aldermore-proprietary developer portal or API was confirmed; the specs below represent the shared UK Open Banking (OBIE) standard, unverified for this bank.

## APIs
- [Open Data API (OBIE Standard)](https://openbankinguk.github.io/opendata-api-docs-pub/v2.4.0/): public reference data (products, ATMs, branches)
- [Account & Transaction Information API (OBIE Read/Write)](https://openbankinguk.github.io/read-write-api-site3/): FAPI-secured AIS
- [Payment Initiation API (OBIE Read/Write)](https://openbankinguk.github.io/read-write-api-site3/): FAPI-secured PIS
- [Confirmation of Funds API (OBIE Read/Write)](https://openbankinguk.github.io/read-write-api-site3/): FAPI-secured CBPII
